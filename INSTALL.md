# Installing V1.0

English translation patch for **Shiritsu Justice Gakuen: Nekketsu Seishun Nikki 2 (Japan), SLPS-02120**, on PlayStation.

1. Extract the V1.0 ZIP.
2. Start with the original, unmodified Japanese BIN/CUE. Do not apply this patch to an earlier English version.
3. Apply **Justice-Gakuen-2-English-V1.0.bps** to the original BIN with a BPS-compatible patcher, such as [Rom Patcher JS](https://www.marcrobledo.com/RomPatcher.js/).
4. Save the patched image as **Justice Gakuen 2 - English V1.0.bin** beside the included **Justice Gakuen 2 - English V1.0.cue**.
5. Load the CUE in your emulator. Supply your own BIOS if required.

The boot support message displays for approximately four seconds, then the game starts normally.

Back up your memory card before switching versions. Load a normal in-game save rather than an old emulator save state. If your emulator names memory cards after the game filename, copy your existing card to the V1.0 name while the emulator is closed; retain the original as a backup.
